# Firmas digitales para PDF de Kinésica ATM

Coloca en esta carpeta las imágenes de firma/sello digital de los profesionales:

- `norberto.png` : Firma y sello del Lic. Norberto Brude.
- `maria.png` : Firma y sello de la Lic. María.

### Recomendaciones de imagen:
- Formato: PNG con fondo transparente (o fondo blanco).
- Resolución recomendada: entre 300x100 px y 500x200 px.
- Si el archivo no existe todavía, el sistema imprimirá la línea de firma, aclaración y matrícula del profesional sin errores.
